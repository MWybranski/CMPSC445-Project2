# CMPSC445-Project2
## Project Description
For this project, we were tasked to create an application that showcases our idea of the “Best of PA”. After much deliberation, we decided to narrow our focus to Pennsylvania’s myriad museums. Using a dataset generated with the help of a Google Maps web scraper, we investigated Pennsylvania’s vibrant museum scene using machine learning algorithms to gain insights and crown the “Best Museums of PA”. 
Our datasets obtained via the web scraper gave us invaluable information such as museum category, museum rating, and up to 100 user-written reviews per museum. We used these data points to perform sentiment analysis, clustering analysis, and correlation analysis.
In addition to the machine learning dimension of this project, we also worked to create a simple web-based application using FastAPI for the backend and Streamlit for the frontend.

## How to run
- Open project folder in VS Code
- Create a virtual environment and install requirements
- Run the app using streamlit run .\streamlit_app.py
- The default web browser will open a new tab
